Features & Syntax
  • Simple placeholders: {{variableName}}
  • Nested objects: {{object.property}} or {{object.nested.value}}
  • Array access: {{items.0}} or {{users.1.name}}
  • Array iteration: {{#each arrayName}}...{{/each}}
  • Inside loops: Access properties with {{fieldkey}} or {{this.fieldkey}}
  • Loop helpers: {{@index}}, {{@first}}, {{@last}}
  • Grid Editor: Edit array data in a spreadsheet format, then sync to JSON
  • Missing values will show as [undefined]
